# solar-battery-monitoring-system.
Overview 
A KiCad electronic design project for a proposed solar-powered lithium-ion battery monitoring system. 


Objectives 
- Design the circuit schematic. 
- Convert the schematic into a PCB layout. 
- Explore the integration of battery charging, voltage/current monitoring and display functions. 


Components 
- ESP32 
- TP4056 charging module 
- INA219 voltage/current sensor 
- OLED display 
- 18650 lithium-ion battery
- Solar panel 
 

Design Tools 
KiCad — schematic capture and PCB layout. 

 
Design Files 
- “schematic/” — schematic PDF and native KiCad file. 
- “pcb/” — PCB layout and native KiCad file. 
- “images/” — screenshots of the schematic and PCB. 

 
Project Status 
Schematic and PCB design stage. Physical fabrication and hardware testing have not yet been completed. 

 
Future Work 
- Review the schematic and PCB design. 
- Verify electrical connections and design rules. 
- Fabricate the PCB and test the system when hardware access is available.
